# 个人笔记发展史

2021～2022年用的是Notion和 Marginote，再到后面大三上下用的是Onenote，后面考研那段时间用的是 Typora和 Prodrfts， 接着很长一段时间都没怎么系统记过笔记，又用回过一段时间 notion（博一上），后来博一上接触了 obsidian，开始常识使用 Obsidian➕Claudian 进行笔记管理，但它的缺陷就是属于纯 Markdown，适合 Agent 去阅读，但并不适合人类阅读，后来也是一个偶然机会,在博一下的时候又一个需求，就是 PPT 需要通过一些 HTML 制作表格，来提高信息密度，后面是做 OVS 综述那段时期突然想到好像所有笔记都可以用 Html+Css+Json 来实现和记录，所以就有了第一个站点，[租房对账表](https://rent.thebear617.cn),接着我在想的是猫猫的信息能不能也从 Obsidian 中剥离出来，于是就有了猫猫手册的雏形，但是那时候不知道组件、布局、交互、配色这些，所以原型都是 AI 靠自己的理解手搓出来的，一开始还是顶部栏切换，后面才开始有侧边栏，转机是有一天我看到了别人的 javaguide，然后就想让 agent 模仿它的风格来，也就是 Vue3 和 Vuepress 之类的风格，但后面发现这种方法得到的网站并不符合我的审美和交互逻辑，于是就在这个交互和书写之间寻求平衡，找到了 Astro，非常好的一个框架，于是陆陆续续把所有站点都升级为了 Astro 框架，在此期间有一天突然觉得组件应该要看板化，增加信息密度，于是去 notion 找了很多灵感，从猪窝开始升级，接着就是猫猫手册，而在猫猫手册的升级过程中发现了 gpt 的 image2 模型十分好用，他会根据你当前的布局和交互逻辑生成非常美观的 UI，接着就可以让 agent 根据 UI 稿分阶段来还原，非常的使用，在此过程中我也不断地根据自己的使用经验来完善各个站点的笔记和数据交互，比如说文件名、slug等的统一前后缀，比如说引入侧边 TOC 和悬浮框，比如说不断优化自己的 taxonomy，开发还是能反哺到很多东西上的，正所谓：“我们塑造工具，工具又反过来塑造我们。“以下是有序列表形式的[^笔记形式发展时间线]
