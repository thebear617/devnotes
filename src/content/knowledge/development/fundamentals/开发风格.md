# 文件命名风格

## 常见命名风格表

| 风格 | 示例 | 说明 | 在文件名和 URL 中的特点 |
| --- | --- | --- | --- |
| kebab-case | `file-naming-conventions` | 全部小写，单词之间用连字符 `-` 连接；形状像烤串（kebab） | 清晰、跨平台稳定、适合链接 |
| snake_case | `file_naming_conventions` | 全部小写，单词之间用下划线 `_` 连接 | 常见于数据字段和 Python 变量 |
| camelCase | `fileNamingConventions` | 首个单词小写，后续单词首字母大写 | 常见于 JavaScript 变量，不适合长文件名 |
| PascalCase | `FileNamingConventions` | 每个单词首字母大写 | 常见于组件、类与类型 |

在文件名和 URL 中，kebab-case 通常清晰、易读，也避免了大小写在不同系统上处理不一致的问题。
