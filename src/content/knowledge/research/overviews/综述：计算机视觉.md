 SAM 1/2 想做的是


[sam3](https://sam3ai.com/open-vocabulary-segmentation/)用于开放词表分割

- PVS（Promptable Visual Segmentation，可提示视觉分割）＝的任务名
         答的是"这个位置是哪个对象？"，prompt 是 point / box / mask，必须"在图上指"

- PCS（Promptable Concept Segmentation，可提示概念分割）＝ SAM 3 新增
         答的是"这个概念包含哪些对象？"，prompt 是文本 / 图像 exemplar，按"概念"找
 
- PVS 答的是'这一个对象是什么'，PCS 答的是'这一类对象都在哪'"——SAM 2 的 prompt 是空间锚点（哪里），SAM 3 的 prompt 是语义概念（什么）

- PVS: 你指哪里我切哪里，PCS：你描述什么我切什么


 - 广义"上下文分割"（Contextual Segmentation）：利用图像上下文信息的经典分割思路（如 PSPNet 金字塔、ASPP）。这个不是你要的。
    - 狭义 In-Context Segmentation (ICS)：给定一张参考图 + 它对应的标注 mask（"一次演示"），在查询图上分割任意概念——可以是物体、部件、甚至个性化实例（比如"我家的猫"）。灵感直接搬自 LLM 的 in-context learning：你给我一个例子，我就能照着切。代表工作：
      - SegIC（ECCV 2024）：DINOv2 + 分割解码器微调，域内强泛化差
      - GF-SAM（NeurIPS 2024）：DINOv2 语义对应 + SAM 画 mask 的免训练组合
      - INSID3（CVPR 2026）：极简派，单一 DINOv3 自监督骨干，零训练，SOTA +7.5 mIoU，300ms 出 mask
