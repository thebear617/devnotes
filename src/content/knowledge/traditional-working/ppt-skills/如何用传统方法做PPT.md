# 案例集合

## 一、人物照 → 立体首图（PPT 形状相交 + 纹理填充）

### 1. 核心思路

只用 PPT 自带的形状相交 + 图片纹理填充，几步做出「人物从背景中浮现」的立体质感。核心是拿自定义形状当「切刀」裁剪图片，再加一层灰化半透明原图做底色——不需要 PS，不需要 AI 生成，完全在 PPT 内完成。技法来自 B 站 PPT橙子的[演示视频](https://www.bilibili.com/video/BV1ExKw6REZZ/)。

![效果图](/images/ppt-skills/古法PPT-首图-1.jpg)

### 2. 操作步骤

#### 1. 抠出人物

插入人物原图后，插入一个斜纹形状（插入 → 形状 → 斜纹），拉大到覆盖人物区域，拖动斜纹形状的**黄色控制点**调整斜边的宽度和角度。点击两次「向右旋转」将斜纹调整到合适的倾斜方向，拖到人物右下角。然后按住 **Ctrl**，**先选中图片**，**再选中斜纹形状**（顺序不能反），顶部菜单选择**形状格式 → 合并形状 → 相交**，人物便被按斜纹轮廓抠出。

#### 2. 灰化背景

再次插入同一张原图，选中后点击「图片格式 → 颜色」改成灰色，再将灰色图片的**透明度设为 90%**。

#### 3. 叠加纹理

**剪切**这张灰色背景图（Ctrl+X），然后选中抠出的人物图，右键 → **设置图片格式 → 图片纹理填充 → 剪切板**。将抠出人物**重叠摆放**在原图人物位置，形成「灰色背景 + 彩色人物」的层次。

#### 4. 添加文案

粘贴文案到合适位置，调整字体、大小和颜色即可。

### 3. 注意事项

<ol>
<li>
<span class="tip-label">选中顺序不能反</span>
<div class="tip-detail">

合并形状中的「相交」以**先选中的对象**为底。必须先选图片再选形状，否则交出来的是形状区域内的图片碎片，而不是抠出来的人物。

</div>
</li>
<li>
<span class="tip-label">形状不是只能矩形裁剪</span>
<div class="tip-detail">

斜纹形状只是一个例子——三角形、圆形、波浪形，任何自定义形状都能当「切刀」。拖黄点改变斜度、旋转角度可以做出完全不同的裁切效果。

</div>
</li>
<li>
<span class="tip-label">纹理填充比直接叠图更稳</span>
<div class="tip-detail">

如果直接用 PNG + 透明度叠放在灰色背景上，排版时两个图容易跑偏。纹理填充是将背景「写入」人物图层的属性中，移动人物时背景跟随，不会错位。

</div>
</li>
</ol>

### 4. 使用建议

- **人物介绍页首图**：立体浮出效果天然适合演讲者介绍、团队页和个人主页。
- **产品封面**：产品图代替人物照，同样的技法做出「产品从背景中悬浮出来」的视觉效果。
- **配色自由度大**：背景灰化 + 透明度的参数可以换成任何色调，换紫色就是科技感，换暖黄就是复古风。
