开发笔记 v0.19.1 为本地 CMS 补齐 Markdown 图片资产的完整生命周期：从剪贴板粘贴上传，到稳定目录、语义化改名、实时渲染与删除清理。

## 图片粘贴与上传

- 在 Markdown 编辑区直接使用右键粘贴或 `Command + V`，CMS 拦截剪贴板图片并将 Markdown 图片引用插入当前光标位置。
- 上传接口限制单张图片不超过 2 MB；超过时提示“大于这个尺寸，请进行压缩处理”。
- 按集合类型和文章稳定标识建立图片目录，上传文件初始使用 UUID 文件名，并保留图片类型校验。

## 路径与改名同步

- 知识库、Debug 库和时间线分别使用对应集合及条目的图片目录；后台编辑 Markdown 图片文件名时，同步改名本地文件。
- 文件名为空或引用不完整时阻止保存并显示兼容提示；无法通过正常状态推断原文件时，使用同目录唯一孤立文件进行恢复。

## 删除与渲染

- 每次保存或删除文章时扫描全部 Markdown 引用；只有最后一处引用移除后，图片才移入系统废纸篓，避免误删仍被其他文章使用的资源。
- 开发服务器直接提供动态创建的图片目录，粘贴后不需要重启 Astro 即可预览。

## 两站一致性

- 常识笔记同步采用按领域目录的图片资产规则，DevNotes 与 LifeNotes 的 CMS 接口、2 MB 校验和图片生命周期处理保持一致。
- 验收覆盖多处引用保留、最后一处引用清理、文章删除清理，并通过两站生产构建。
