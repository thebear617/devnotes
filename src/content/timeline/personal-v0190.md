路由表改为独立的全宽页面，并围绕同一份链接数据提供三种浏览方式。

## 多视图路由表

- 新增分组、列表和瀑布流视图，切换时各面板互斥显示
- 列表视图展示名称、分类、标签、添加时间和外链操作，支持按添加时间正序或倒序排列
- 瀑布流基于站点 favicon、分类色彩与不同卡片高度呈现链接信息；本地文件保留为非跳转卡片

## 检索与筛选

- 搜索会同步过滤三种视图，并更新分组内的链接数量
- 新增分类和标签筛选面板；可组合一个分类与一个标签、再次点击取消或一键清除
- 链接数据补充分类标识、图标、标签和添加时间，供各视图共用

## 验证

- `npm run build` 与 `git diff --check` 通过
