- 知识库新增 Markdown 有序列表层级渲染，按层级使用数字、字母和罗马数字标记
- Markdown 表格改为统一的包裹式渲染，补充横向滚动、圆角、边框、表头和单元格样式，改善宽表格的阅读体验
- 新增全局脚注式悬浮框扩展语法：支持把脚注内容转成行内浮层，点击后保持展开，再次点击可以收起，并与正文自然衔接
- 将《随想-0803》中的分类表格、固定习惯和二值习惯改为悬浮框内容，同时保留 Markdown 文件的轻量编辑形式
- 新增《Markdown 语法综述》知识文章，归档到「编程 / 基础」，整理 Markdown 核心语法、GFM 语法和本站扩展语法
- OpenCode 模型路由文章补充会话索引，便于从知识库回溯对应开发记录
- 版本号 0.8.0 → 0.9.0

本次版本集中完善 Markdown 内容的展示与编辑两端：文章阅读侧增强表格、列表和悬浮内容的表现，编辑侧尽量保持 Markdown 原文简洁，降低组件化内容对写作顺序的干扰。
