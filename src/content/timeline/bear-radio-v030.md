熊电台 v0.3.0 围绕“更快识别当前会话、更自然地整理会话、更少打扰地反馈工作状态”完成一轮桌面端体验收束。

## 会话与标签交互

- 在输入区发送按钮左侧显示当前绘画使用的模型名称，统一隐藏后端前缀与“模型”等冗余语义。
- 会话标签支持双击和右键重命名，名称与本地插件会话保持双向同步。
- 标签支持长按拖拽排序；拖拽过程采用透明占位与明显挤压反馈，保留顶部栏与标签栏的拖拽职责边界。
- 标签补充最后一条消息的日期与时间，并用临时状态点提示已完成但尚未查看的会话。

## 工作状态与本地会话

- 进行中的会话收起中间思考过程，只显示持续工作计时与轻量状态提示，完成后再展示结果。
- 顶部标签在工作中显示进行状态，完成后显示临时绿色提示点；进入对应标签后提示自动消失。
- 新建会话入口隐藏暂不需要的 Web 模式，接入本地会话面板默认展示 Claude，并以固定高度滚动容器显示本地会话列表。
- 接入本地会话界面重新整理 Agent 选择、本地会话列表、插画和操作区的布局，保留本地插件中的原始会话记录。

## 产品化收束

- 应用名称、项目目录、远端仓库和 macOS App 图标统一为 Bear Radio（熊电台）。
- 调整桌面窗口与弹窗的布局居中方式，避免 macOS WebView 对 transform 合成层重新栅格化造成文字和边框发糊。
