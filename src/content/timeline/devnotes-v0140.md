开发笔记新增本地 CMS 后台，支持内容集合管理、结构化字段编辑、Markdown 实时预览和编辑器与预览之间的双向定位。

## CMS 能力

- 新增知识库、开发时间线和 Debug 库三个内容集合的本地管理入口。
- 按内容集合提供字段配置、枚举分类、自定义下拉菜单、多选分类和必填校验。
- 支持文章列表、搜索、筛选、排序、新建、读取、编辑和手动保存。

## Markdown 编辑与预览

- 增加 Markdown 工具栏和实时预览，复用站点现有的数学公式、脚注、表格与悬浮内容处理链路。
- 为预览节点标记源文件行号，实现 Markdown 编辑区与预览区之间的双向定位。
- 本地 CMS 通过 Vite middleware 提供读写和预览接口，生产构建时自动移除 `/admin` 输出。
