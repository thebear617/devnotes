常识笔记 v1.5.0 是一次顶层分类学重构，依据官方《国民经济行业分类》口径，把站点内容按「产业坐标（供给侧，向外观察行业）」与「自我坐标（需求侧，我的生活与思考）」重排为五大领域。

## 板块层变化

- 撤销 `ai` 板块：AI 技术实践内容删除或迁往 devnotes，行业观察并入服务业新增一级「信息与AI产业」。
- 撤销 `finance`：投资/宏观经济并入服务业（新增一级「宏观经济」），家庭财务并入生活板块（一级「家庭财务」）。
- `consumer-tech` 更名并扩容为 **工业**：一级对齐第二产业四门类（采矿 / 制造 / 电力燃气水 / 建筑），制造下先开 汽车 / 数码产品。
- 撤销 `biology`：宠物养护知识迁往猫猫站（cats 行为科普）；植物科普并入 humanities。
- `humanities` 更名 **人文与自然**：一级统一为四个观察对象（空间与城市 / 人与社会 / 文化与语言 / 自然与生态），二级用两字词（城市 / 人生 / 文字 / 植物）。
- `life` 更名 **生活与美食**：八个一级收敛为五个（美食 / 校园与学习 / 财务 / 居家与健康 / 生活速查）。
- 新增 **随笔** 领域：随想（建站规则）与草稿箱（未整理），承接草稿与摘录；默认落地页改为生活与美食。

## 内容层变化

- 内容按「综述/合集聚合」写法重排：猫行为、手机使用、经济概念、酒店行业等合并为聚合长文；旧板块约二十篇短文按新分类归档或删除。
- 同步更新板块枚举、内容路径映射、动态路由、本地 CMS 领域下拉与默认页跳转。
- 新增「建站规则：分类学更迭记录」，回填 2026-08-23 一二级枚举树诞生与本次重构的分类树留档。
