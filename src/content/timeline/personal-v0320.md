熊窝个人主页这一版做了一次信息架构的拆分。此前首页是一张「轨道式」画布（`HomeCanvas`）——用轨道、卫星卡、环绕圆点把天气、日历、歌单、路由入口等一次性堆在首屏，信息密度高但视觉上偏装饰、也难维护。这一版把首页与仪表盘重新划分职责：**低信息密度的日常概览进首页，需要长期跟进的清单与追踪留在仪表盘**。

## 首页改生活概览

- 新增 [`LifeOverview.astro`](src/components/LifeOverview.astro)，替换并删除旧的 `HomeCanvas.astro`（连同其 700 余行专属样式）。
- 概览内容包括：渐变天空、西安 / 南宁 / 威海三城天气（点击城市卡片可看未来 5 天预报）、可翻月日历、GitHub 主页与常用仓库、网易云歌单（桌面端嵌入播放器、手机端跳转网易云）。
- 首页画布宽度与关系管理（CRM）页统一为 `width: min(1400px, calc(100vw - 20px))`，≥1440px 居中、≥960px 顶部留白 5rem，两页视觉骨架对齐。

## 仪表盘瘦身

- [`LifeDashboard.astro`](src/components/LifeDashboard.astro) 只保留两块：**想做清单** 与 **追踪看板**；天气 / 日历 / GitHub / 歌单全部移出到首页。
- `SiteLayout` 相应移除 `hideSidebar` / `home-shell` / `home-layout` 分支，所有页面统一走胶囊导航布局。

## 想做清单

- 新增 [`WantList.astro`](src/components/WantList.astro) 与数据源 [`want-data.ts`](src/data/want-data.ts)。
- 定位是「轻度、无期限、想起来就做」的清单：每条只有 `{ text, tag?, added? }`，没有排期、状态机、归档，与任务看板刻意区分——前者是念想，后者是项目。
- 展示为暖纸色胶囊 chip，空列表有兜底文案；日常维护方式是「说一句加进去、做完了删掉」。

## 发布

- 发布提交：`785b914 feat(v0.32.0): 首页与仪表盘拆分 —— 首页改生活概览，仪表盘只留想做清单 + 追踪看板`。
- 同批次另有一条任务看板数据同步提交 `3624e9f`（与本次重构无关，拆分提交）。
