熊窝任务看板在 v0.30.2「按小时」视图之后，这一版的重点从「能排期」转向「每天用起来顺不顺手」：进站第一眼是甘特图而不是看板，点横条就能改阶段名与阶段区间，阶段名的输入框也不再被长名字截断。同时补上「按小时排期改回按天排期」这条此前缺失的退路。

## 进站默认甘特图

- `currentView` 初始值由看板改为甘特图：第一眼看到的是「当前在推进什么、排到哪一天」，更贴近当天的工作焦点；不记忆上次的视图切换，每次进站都从甘特图开始。
- 脚本执行前的骨架屏不再摆「待办 / 进行中 / 已完成」三列，改为一句话占位「正在排布甘特图…」，避免默认视图闪一下看板。
- 甘特图底部图例行只留颜色图例（进行中 / 已完成 / 未开始阶段）；「拖动整条移动计划，拖动两端调整日期」「点击横条即可编辑阶段」这类操作提示统一并到标题「任务甘特图」下方那行副标题里，图例行扫一眼只对颜色。

## 点击横条编辑阶段

- 横条的「点击」与「拖拽」共用同一套 pointer 逻辑区分：抬手时排期与按下时完全一致，即判定为点击，直接打开阶段编辑弹窗；真拖动（含拖出去又拖回原位）仍走原来的写排期逻辑。
- 阶段色块新增 `data-phase-id`，点中某一段时弹窗里的光标直接落在这一段的名字上；点阶段分割线但没拖动，同样按点击处理（打开左侧那一段）。
- 弹窗入口统一为 `openPhaseEditor(itemId, phaseId?)`，左侧「分阶段」按钮与横条点击共用；按天横条本身是 `button`，聚焦后回车 / 空格也能打开，键盘可达。

## 阶段编辑弹窗

- 去掉弹窗顶部「划分任务阶段」的橙色 kicker（与弹窗内容重复），只留任务名当标题。
- 阶段名由单行 `input` 换成 `textarea`：外观沿用原来那个输入框（同样的内边距 / 边框 / 圆角 / 底色 / 字号，单行时与其它字段等高），长名字在框内换行显示完整，最多约 3 行，再长才在框内滚动；不做拖拽缩放。
- 高度由 `autosizePhaseTitleField` 按 `scrollHeight` 实时算出，窗口尺寸变化时再量一次；回车不再换行而是结束这一段编辑，中文输入法确认候选词的回车不会被抢。
- 打开弹窗时光标落在「当前阶段」（进行中 > 未开始 > 第一段），点「＋ 添加阶段」后光标落在新阶段名上并全选占位名；`refresh()` 重建弹窗 DOM 后靠 `phaseFocusPending` 把光标放回去。

## 按小时改回按天

- 小时轴任务行新增「转为按天」：丢弃 `plannedStartTime` / `plannedEndTime`，日期沿用原首尾两天，任务回到日期轴。
- 阶段先剥离整点端点，再按天平均铺满整段；阶段数多于原天数时把计划结束日顺延到刚好放得下（confirm 说明），避免按天归一化时把放不下的阶段直接截断丢失。
- 转换成功后自动切回「按天」视图并提示新的计划区间，避免任务离开小时轴后不知去向。
