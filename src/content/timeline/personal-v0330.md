熊窝任务看板在 v0.32.0 之后把「时间取向」显式拆成三个视图——看板（当下）、甘特图（计划）、复盘（过去），同时给等待中的进行中任务加了「搁置」状态。已完成任务不再挤在甘特图上：甘特图只回答「接下来怎么排」，历史回顾交给按周铺开的复盘清单。

## 三视图：看板 / 甘特图 / 复盘

- 视图切换由两个扩到三个，第三个「复盘」= 过去一年的完成热力图 + 已完成任务清单，两个只读的历史视角放在一起看。
- 原先 header 里独立的「📜 查看历史」折叠按钮删除——它会把热力图叠在当前视图上方（在看板里等于压在卡片列上）；热力图现在只活在复盘 tab。
- 甘特图工具栏的「显示已完成」勾选框一并去掉：已完成任务不再上时间轴，所以勾选前后行数从 17 行回到 5 行，页面高度约 1275px 回到 375px。

## 复盘清单

- 已完成条目按**周**分组（周一起算），组头写周区间 + `完成 N 项 · 共 N 天`，本周带徽章；组内按完成日倒序（`completedAt` → 末阶段结束日 → `plannedEnd` → 目标日期）。
- 每条一行：完成日（悬停出完整日期与相对时间）+ 看板图标 + 标题 + 右侧 `8/29—9/18 · 21 天`；有阶段时补一条**按阶段时长成比例**的缩略条 + 一行阶段名，悬停出每段的起止与耗时。
- 分页每页约 20 条，但以「周」为最小分页单位（不把一周切到两页），页码越界自动夹回；当前 74 项 → 5 页。
- 无排期的已完成条目也能进清单（只显示完成日 + 标题）——这类记录以前在甘特图里根本不可见。

## 搁置

- 任务级新增可选字段 `pausedAt`（搁置起始日）：等待 / 被挤掉排期的进行中任务一键搁置，从甘特图下线、等待期在时间轴上留白，而排期、阶段、进度一个都不删；卡片出「搁置中」徽章与「恢复排期」，原计划已过期则是「恢复并顺延」。
- 恢复只清 `pausedAt`、不重排任何日期，原排期与阶段原样回轴；甘特图工具栏提示「N 项搁置中未上轴」，按天 / 按小时两个视图都在。
- 搁置项收进「进行中」列底部折叠区。与「移出甘特图」的区别：后者会清掉排期与阶段，等于退回普通待办。

## 命名规范落地

- 「新增 / 编辑任务」弹窗按「站点 v版本：需求一｜需求二」拼标题：站点下拉（9 个统一短名）、版本框以该站当前版本作占位（构建时直接读兄弟仓库 `package.json`，不手工维护）、需求名称与具体需求双向联动、需求清单自动编号 ①②③。

## 甘特图与细节修复

- 阶段名不再按 4 字硬截断（够宽显示全名，窄到放不下时只留序号，与左侧进度点、阶段弹窗编号一一对应）；任务标题改两行显示；图例「已完成」改「已完成阶段」。
- 目标日期改成可选的意向日，相对时间说人话，不再出现「2 个月前 / 原始日期」这类像逾期的写法。
- 任务弹窗关闭浏览器表单历史提示（`autocomplete="off"`）。
- 修复归档与活动任务撞 id 导致的状态串号：撞号时归档条目不再吃状态补丁，已完成的旧记录不会再被套上搁置 / 排期；甘特图的搁置统计只看活动任务。
