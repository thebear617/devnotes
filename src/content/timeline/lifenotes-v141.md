常识笔记 v1.4.1 完成本地 CMS 的一次可靠性整理：内容文件位置不再依赖手动填写，自动保存的日期与缓存写入也有了明确、可验证的边界。

## 内容路径与编辑结果

- 领域、一级分类、二级分类和标题共同生成最终 Markdown 路径；后台展示完整路径，标题直接作为文件名，避免冗余输入和目录错配。
- 内容路径映射在管理后台与本地写入中共用，修复 CMS 后台偶发的文章列表为空问题。
- 每次自动保存、立即保存或 Cmd/Ctrl + S 保存都会将 `updated` 写为当天日期；更新日期字段改为只读，并在保存完成后回显服务端日期。

## 稳定保存与验收边界

- 普通开发服务改为单实例，避免多个 Astro 进程并发重命名 `.astro/data-store.json` 引发间歇性保存报错。
- 新增 `npm run dev:verify -- --port <空闲端口>`：它在临时副本中运行 CMS，使用独立缓存和内容根目录，Agent 的浏览器验收及其自动保存不会影响真实文章。
- README 与 Agent 约定同步说明 CMS 自动更新时间和隔离验收方式。
