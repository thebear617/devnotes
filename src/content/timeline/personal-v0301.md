熊窝任务看板在 v0.30.0 在线新增与删除任务的基础上，补齐「已添加任务无法修改」这一缺口：卡片新增「编辑」按钮，打开与新增任务一致的弹窗，保存后直接更新任务资料并保持现有状态与排期数据。

## 在线编辑任务

- 待办、进行中和已完成的活动任务均可通过「编辑」按钮打开编辑弹窗；归档任务继续保持只读。
- 弹窗回填并保存看板分类、任务名称、链接、备注和目标日期，支持把任务移动到其他看板。
- 本地 dev server 新增 `POST /__todo_file` 的 `update` 操作，静态资料写回 `src/data/todo-data.ts`；任务状态、排期和完成日期仍由 `todo-state.json` 管理。
- 编辑保存后同步内存看板数据，分页和当前页面即时刷新；线上构建继续保持只读。

## 发布与验证

- 版本号由 `0.30.0` 升至 `0.30.1`，同步更新 npm 元数据与锁文件。
- 发布提交：`6b9b260 feat(v0.30.1): 任务看板在线编辑任务`。
- `npm run build`、`npm run todo:validate` 和目标文件 `git diff --check` 均通过。
