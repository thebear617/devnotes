熊窝完成首页工作台视觉改版：首页不再直接铺开完整路由表或仪表盘，而是以“今天也慢慢过”为中心节点，将个人站点、AI 工具、科研学习、购物娱乐和生活摘要组织成环绕式入口。根路径继续保留路由表作为默认入口，新首页通过 `/home/` 独立访问。

## 首页工作台

- 新增中心节点、轨道装饰、天气/日历/歌单/GitHub/习惯摘要和主要路由簇，形成静态环绕构图。
- 桌面端采用中心围绕与轻微错落的布局，移动端降级为稳定的线性阅读顺序，不依赖持续旋转动画。
- 首页只承担快速查看和快速进入，完整路由表与生活仪表盘仍保留在独立页面；根路径默认进入路由表。

## 导航与页面层级

- 将原侧边栏收起状态统一为左上角三按钮胶囊导航，只保留首页、路由表和生活仪表盘入口。
- 首页不作为路由表或仪表盘的默认激活页；`/routes/` 和 `/dashboard/` 分别保持各自的当前页状态，路由表默认进入分组视图。
- 路由表保留分组、列表和瀑布流三种视图，以及搜索、分类筛选、标签筛选和快捷键操作。
- 无侧边栏后，生活仪表盘最大宽度从 1180px 调整为 1240px，同时保留移动端响应式断点。

## 数据与实现整理

- 将仪表盘天气、歌单和 GitHub 展示数据拆分到独立数据模块，供首页摘要和详情组件复用。
- 抽出共享导航数据，统一 Astro 页面和导航组件的链接、图标与激活状态。
- 保留追踪看板的 localStorage、发布快照和同步校验链路，首页只读取轻量摘要。

## 验证

- `npm run build` 构建通过，共生成默认路由表、首页、路由表独立页和生活仪表盘 4 个页面。
- `npm run tracker:validate` 通过，追踪快照数据保持有效。
- 在 1280px、1440px 和 390px 视口完成浏览器视觉检查：胶囊导航、搜索工具栏和仪表盘内容无重叠，页面无横向溢出。
