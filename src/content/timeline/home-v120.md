猪窝新增「每日看板」页面，从熊窝个人主页迁移而来，使用 Astro + 原生 JS 重写，不引入额外框架。

## 每日看板

- 四分类 kanban（🎬 视频 / 🔍 科研 / 💻 编程 / 🏠 生活），每个分类独立三列（待办 / 进行中 / 已完成）
- 统计条（总数 · 已完成 · 进度百分比）和「📜 查看历史」归档面板
- 历史按分类与日期分组整理，折叠展开，支持链接跳转
- 看板页面宽度扩展至 1200px，适配三列布局
- 交互逻辑用原生 JS 事件委托实现，编译后脚本仅 2.01 kB（gzip）

## 数据与架构

- 新增 `src/data/todo-data.ts` 提供 TypeScript 类型化的看板数据
- 新增 `src/scripts/todo-board.ts` 用原生 JS 实现全部过滤、渲染与历史归档逻辑
- 新增 `src/pages/todo-board.astro` 作为独立页面路由
- 看板 CSS 从熊窝原样迁移，两站共享设计 token 无冲突

## v1.2.1 增量（patch）

- 「待办」列去掉 `date <= today` 限制，按 `date` 升序排，让未来 todo 自然落到今天 todo 后面
- 卡片同时展示 due date（📅）与 create day（🕒），文案统一用相对时间
- `relativeTime()` 扩展支持未来日期：明天 / 后天 / N 天后 / N 周后
- 未来日期文案改为 `M月D日`（如 `7月26日`），不再用相对表达
- 编程板清理：删除 `doing` 状态的「复现别人的项目」（粒度太笼统）
- 通讯订阅新增子分类 `梯子节点`，承载魔戒等梯子/代理类订阅
- 支出分类拓展：`居家生活/厨房用品`、`市内出行/火锅麻辣` 等子项陆续落地
