开发笔记 v0.15.3 聚焦本地 CMS 的保存可靠性：开发笔记和常识笔记后台在编辑停止后自动写入本地 Markdown 文件，同时保留立即保存入口作为即时触发和异常兜底。

## 双站点后台自动保存

- Markdown 正文和文章元数据统一进入自动保存流程，停止编辑约 900ms 后提交到本地 CMS 接口。
- 保存请求串行执行，并用草稿版本号判断响应是否仍对应当前内容；保存期间继续编辑时会自动补存，不会被旧响应覆盖。
- 切换文章、新建文章和离开页面前会先尝试完成当前草稿的保存，保存失败时明确提示并允许用户决定是否继续。
- 后台状态栏展示等待自动保存、保存中、已自动保存和错误状态；“立即保存”按钮和 `Command/Ctrl+S` 仍可用于即时保存。

## 版本记录

- 开发笔记版本由 `0.15.2` 升至 `0.15.3`。
- 常识笔记版本由 `1.1.2` 升至 `1.1.3`，同步补充对应时间线记录。
- `devnotes` 与 `lifenotes` 的 `npm run build` 均通过。
