熊窝完成从传统 Vue 单页站点到 Astro 静态站点的整体迁移，并重点重做无畏契约资料库的导航与阅读体验。本版本前序为 v0.14.0（每日看板迁移至猪窝）。

## Astro 迁移

- 新增 Astro 静态构建配置、页面路由和 GitHub Pages 构建工作流
- 首页、路由表、会员记录、英雄联盟和无畏契约均改为 Astro 页面
- 原有静态资源迁入 `public/`，保留无畏契约页面所需的本地 Vue、Marked、数据和英雄头像
- 构建产物统一输出到 `dist/`，页面运行不依赖 CDN、外链字体或远程脚本

## 无畏契约资料库

- 将地图内容改为侧边栏切换的知识库工作台
- 15 个板块合并为 14 个板块：元认知、全地图总表和通用技巧合并为「全局战术总览」
- 重新设计侧边栏、章节标题、地图子导航、表格、Callout、阵容卡和时间线
- 折叠状态使用新的紧凑卡片样式，展开后的攻略内容保留原版阅读排版
- 修复时间线步骤数字未在圆圈内居中的问题，并补充移动端响应式布局

## 验证

- `npm run build` 构建通过
- Vue、数据脚本和页面资源均通过本地检查
- `git diff --check` 通过
