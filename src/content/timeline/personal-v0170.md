熊窝 v0.17.0 完成会员订阅板块的迁出：订阅数据和续费管理统一由猪窝的独立会员订阅页承接，熊窝回归个人主页、游戏资料与路由导航的职责。

## 迁移内容

- 移除会员订阅侧栏入口、页面组件与原数据源。
- 移除熊窝 README 中的会员订阅维护说明，避免形成双份数据入口。
- 猪窝新增 `/membership/` 页面作为唯一维护位置。

## 验证

- `npm run build` 通过；熊窝静态路由不再生成会员订阅页面。
