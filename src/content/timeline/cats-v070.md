猫猫手册在 v0.7.0 统一“西电猫猫”品牌与暖色纸张档案视觉，将首页、知识科普、物资与协作及侧边栏收束为一致的档案体验，同时继续以现有结构化数据和 Markdown 文章为事实源。

## 首页与品牌体验

- 首页重构为猫咪年鉴式封面，保留大头固定首图，补充完整猫咪档案墙、轻量搜索筛选与 15 分钟精选轮换。
- 统一使用“西电猫猫”与“救助运营”表述，替换侧边栏旧线稿为项目内透明背景坐姿猫咪素材，并修复 GitHub Pages 子路径下的资源加载。

## 运营与知识档案

- 物资与协作统一为运营档案页，库存基于真实物资、地点与备注生成统计、索引和默认折叠分类，并补全规格与地点搜索。
- 知识科普以 Markdown 文章为最小单元重构为可检索档案索引，支持分组、宫格、列表视图，以及真实标签、分类和筛选状态侧栏；同时补充标签检索与条件清空。

## 发布与维护

- 版本号由 v0.6.0 升至 v0.7.0，完成 Astro 构建、语法检查与静态路径验证。
