开发笔记 v0.17.1 集中完善本地 CMS 的内容落盘逻辑和开发服务边界，使目录规则、文件命名、自动保存与浏览器验收可以在同一套约束下稳定协作。

## 内容路径与元数据

- 知识库的一级分类、二级分类与标题现在共同生成保存路径：前两者决定目录，标题决定 Markdown 文件名；后台只展示最终路径，不再提供冗余的文件名输入。
- 保存入口在服务端重新校验路径与分类、标题的对应关系，避免前端状态不一致时写入错误位置。
- 每次自动保存、立即保存或 Cmd/Ctrl + S 保存都会将 `updated` 写为当天日期；更新日期字段改为只读，并在保存完成后回显服务端日期。

## 稳定保存与验收边界

- 为普通开发服务增加单实例锁，避免多个 Astro 进程竞争写入同一份 `.astro/data-store.json`，消除间歇性 `ENOENT rename` 保存错误。
- 新增 `npm run dev:verify -- --port <空闲端口>`：它复制 `src/` 到临时目录，使用独立 Astro 缓存和内容根目录，让 Agent 的浏览器验收及其自动保存完全隔离于真实文章。
- 同步记录日常 CMS 与隔离验收的启动约定，便于后续编辑和排查时复用。
