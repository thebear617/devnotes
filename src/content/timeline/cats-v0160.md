猫猫手册 v0.16.0 完成第一轮 API 数据对齐与内容层补齐：以 API 的 99 条记录为目标名单，保留 7 条仅存在于现有网站的猫咪档案，形成 106 条正式记录。

## 档案数据补齐

- 保留现有网站字段名，补齐性格、故事描述、关系、别名、动态、来源编号和来源图片等结构化字段。
- 对 API 中无法确认的信息统一保留“待补充”，不把不明确的状态强行映射为正式枚举值。
- 按人工确认结果处理正式名称、别名、状态、性别与关系语义，关系记录支持后续双向展示所需的结构化数据。
- 为缺少本地图片的档案导入 API 图片，并生成对应缩略图；已有本地图片继续沿用现有资产。

## 数据处理留档

- 保存只读 API 原始导出、候选数据、对齐检查和 staging 快照。
- 增加候选生成、图片下载、缩略图生成和正式数据迁移脚本，保留从原始数据到 `js/cats.js` 的可复现路径。
