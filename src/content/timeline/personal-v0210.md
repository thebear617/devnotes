- 英雄速查从手工维护的 34 位英雄升级为全部 173 位英雄，数据改由 RESG（海克斯大乱斗数据站）公开 API 的静态快照驱动，新增英雄索引、海克斯推荐、外号拼音三个数据文件
- 新增英雄详情抽屉，点开任意英雄可看 RESG 实战海克斯推荐（单/双/三/四 Top5、胜率与对应出装）
- 画廊支持官方定位筛选、外号/拼音搜索与默认/胜率/热度排序；工具栏重构为搜索框居左 + 筛选/排序下拉浮窗
- 新增 fetch-lol-all.py 与 gen-nicknames.py 两个生成脚本，全英雄头像本地化，并清理旧的大写冗余头像
- 修复公式详情视图英雄头像 404（数据路径统一为小写）与无畏契约页返回链接在子路径部署下 404

这是从 v0.20.1 到 v0.21.0 的英雄联盟板块重构，从手工攻略转向 RESG 实战数据驱动，并沉淀出可复用的数据生成与更新流程。
