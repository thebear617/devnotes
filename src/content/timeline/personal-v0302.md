熊窝任务看板在 v0.29.0 分阶段甘特条与 v0.30.1 在线编辑的基础上，为甘特图新增「按小时」视图：任务排期可携带整点时刻，把 1–2 天内的小任务按整点铺成小时序列，甘特条按小时切片、阶段连续闭合到结束时刻。

## 按天 / 按小时切换

- 甘特图工具栏新增「按天 / 按小时」粒度切换；按小时视图把计划区间按整点铺成行序，时间轴以整点小时为刻度，适合需要精确到当天几点的短任务。
- 工具栏左侧为切换开关，右侧保留「显示已完成」与计划区间对齐，与上一版精简后的布局保持一致。

## 整点排期

- 任务排期新增可选 `plannedStartTime` / `plannedEndTime` 整点字段，两端同时存在时任务进入「按小时」视图；阶段弹窗支持为起止填写整点时刻。
- 小时任务阶段按连续整点归一化，后一阶段从前一阶段结束时刻立即开始，末阶段自动收在结束时刻；拖动整条 / 分割缝边界时保持整点对齐。
- 看板卡片阶段缩略条与甘特条均按小时切片着色，短任务在小时轴上可读。

## 同步与校验

- `POST /__todo_sync` 落盘前按小时语义归一化阶段（排序、连续铺满、闭合末段），与前端渲染走同一套逻辑。
- `todo:validate` 与 GitHub Actions 新增整点排期校验：`HH:00` 格式、起止时刻须成对出现、结束必须晚于开始、小时任务各阶段时间端点合法。
- `src/data/todo-data.ts` 的 `TodoItem` 接口与 `todo-state.json` 支持小时排期字段。
