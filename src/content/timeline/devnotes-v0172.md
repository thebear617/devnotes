开发笔记 v0.17.2 重构知识库的分类维度并升级 CMS 编辑体验。分类不再是混在一起的“内容角色”，而是先按一级领域分开“开发”与“实践”，实践再按产出模态细分，让不同产出（PPT、网页、图表、视频、报告）有各自的心得沉淀空间。

## 知识库分类重构

- 一级“开发与实践”拆成 `开发` 与 `实践` 两个一级领域；一级现为 开发 / 实践 / 科研 / 随想。
- 二级按一级联动：实践按**产出模态**分（PPT / 网页 / 图表 / 视频 / 报告，报告为新增），开发保留 基础知识 / 综述 / 学习资源 / 配置记录 / 工具使用心得（工具使用心得新增），科研 / 随想维持综述 / 随笔 / 时刻。
- 删除原“典型案例”二级，37 篇笔记按新分类迁移到对应子目录；文章 `slug` 不变，访问 URL 保持不变。
- schema（`content.config.ts`）、CMS 解析器（`admin/parsers/knowledge.mjs`）与分类枚举同步为新的联动关系。

## CMS 编辑体验

- 二级分类下拉随一级分类联动过滤，不再平铺显示全部子分类；内容归类目录与路径校验同步该联动。
- 列表页“筛选”由吸附在按钮旁的弹出层改为居中的悬浮弹窗（遮罩 + 标题 + 清空 / 完成），下拉统一为自定义样式；筛选下拉展开采用固定定位，避免被弹窗高度裁剪。
- 编辑器字段卡组（内容核心 / 内容归类 / 文件与发布）默认折叠，侧栏工具栏把无用的“刷新”按钮改为“展开 / 收起字段”开关。
