开发笔记 v0.15.2 聚焦本地 CMS 的沉浸式 Markdown 编辑体验：进入编辑后隐藏后台 chrome，让内容编辑和预览成为页面的主要界面，同时保留清晰的退出与保存入口。

## 沉浸式双栏编辑

- 编辑页面采用浅色主题左右双栏布局，左侧编辑 Markdown，右侧实时预览渲染结果。
- 左侧编辑区保留格式工具栏，减少常用 Markdown 操作的记忆成本。
- 隐藏原有后台 chrome，仅保留与当前编辑任务直接相关的界面。
- 右上角显示“已读取”状态，并提供退出按钮和保存按钮。

## v0.15.3 补丁：双站点后台自动保存

- Markdown 正文和文章元数据在停止编辑约 900ms 后自动保存，开发笔记和常识笔记后台统一使用这套流程。
- 保存请求串行执行，并用草稿版本号判断响应是否仍对应当前内容；保存期间继续编辑时会自动补存，避免旧请求覆盖新内容。
- 切换文章、新建文章和离开页面前会先尝试完成当前草稿保存，状态栏反馈等待、保存中、成功和失败状态。
- 保留“立即保存”按钮以及 `Command/Ctrl+S` 即时保存入口；开发笔记版本由 `0.15.2` 更新到 `0.15.3`。
