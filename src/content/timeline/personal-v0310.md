熊窝关系管理（CRM）页在这一版做了一次整体重构。核心不是加功能，而是把此前「信息密度不低、但细节都差一口气」的地方收敛到可用的状态：图表的比例与交互、联系方式的可复制、任务的归档闭环、弹窗形态统一，以及数据看板的排版。

## 活跃度趋势图重做

- 之前的折线图用固定 `viewBox` + `preserveAspectRatio="none"` 拉伸填充，圆点被拉成椭圆、比例失真，而且面积渐变的 `url(#crm-trend-fill)` 从未定义。
- 现在按容器真实像素设置 `viewBox`（等比，1:1），折线改为单调三次平滑曲线（不过冲），补齐渐变面积填充，Y 轴刻度按数据取整，峰值点单独高亮。
- 修复「点开 tooltip → 关闭 → 再也点不开」的 bug：tooltip 元素改为常驻节点、只切换显隐，不再在关闭时 `remove()` 掉唯一节点。

## 联系详情

- 长期未联系提示由独立的红色块改为「姓名旁状态药丸（`N 天未联系`）+ 最近联系行内 chip」，建议文案挂在悬浮 tooltip 上，不再挤占详情面板高度。
- 手机 / 邮箱的复制按钮真正可用：Clipboard API 优先，失败回退隐藏 `textarea` + `execCommand('copy')`；成功后按钮变绿色对勾并弹 toast。
- 相关任务勾选接入归档闭环：勾选 → 确认悬浮窗 → 任务标记「已完成」并归档、移出列表，作为跟进任务时也不再触发提醒。
- 互动记录固定展示最近 4 条；详情底部两侧卡片改为按内容高度，避免被强行拉高导致列表裁切。

## 弹窗形态统一

- 「编辑联系人」由右侧抽屉改为居中悬浮窗（暖色卡片 + 右上角径向渐变 + 弹入动画），与互动 / 任务 / 归档弹窗统一。
- 删除各大标题与弹窗的中英双语 kicker（`PEOPLE IN YOUR CIRCLE`、`TOUCHPOINT LOG`、`NEXT ACTIONS` 等），只保留中文标题。
- 互动弹窗去掉「正在为 XX 记录一次互动」上下文行，标签精简为 类型 / 时间 / 摘要，时间与摘要改为整行堆叠并顶对齐。
- 添加任务弹窗去掉上下文行与「今天 / 3天后 / 下周」快捷日期；归档弹窗按钮右对齐、去掉多余分割线。

## 数据看板

- 去掉「RELATIONSHIP DASHBOARDS / 关系数据看板」标题行，直接以内容开场：第一行 KPI 条，第二行左「待跟进」（套卡片容器）/ 右「互动时间线」。看板宽度与主视图一致，两张卡片按内容自适应，不再强行拉伸。
- 互动时间线保持「约 2 条可见高度」的滚动容器，其余记录可滚动查看；「回到联系人」放在时间线卡片右上角。
- 侧栏「智能筛选」标题与右侧搜索框顶对齐。
