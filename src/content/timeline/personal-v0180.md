熊窝首页从原有路由表调整为生活仪表盘，提供日常信息与常用入口的统一起点。

## 仪表盘组件

- 新增西安、南宁两地天气，以及随本机时间变化的渐变天空组件
- 加入月历、番茄钟与静态 GitHub 个人主页卡片
- 番茄钟继续由第三方组件在浏览器中维护状态，不新增后端或账号数据

## 搜索与导航

- 新增 Google、百度、必应可切换的统一搜索框，直接在新标签页打开结果
- 侧边栏将生活仪表盘设为首个入口，并保留路由表、无畏契约与英雄联盟导航
- 首页和嵌套路由均使用相对路径，确保 GitHub Pages 子路径部署下可正常跳转

## 验证

- `npm run build` 与 `git diff --check` 通过
