开发笔记 v0.16.1 聚焦本地 Markdown CMS 的文件生命周期管理，补齐文章删除和路径重命名逻辑。

## 文章删除

- 后台增加确认删除流程，确认后通过 macOS Finder 原生回收操作将 Markdown 文件移入废纸篓，保留恢复能力。
- 非 macOS 环境保留跨文件系统的复制兜底，避免直接重命名失败后遗留原文件。

## 文件路径重命名

- 自动保存时同时提交原路径与新路径。
- 后端先重命名原 Markdown 文件，再写入新内容，避免路径修改后同时留下旧文件和新文件。
- 目标路径已存在时拒绝覆盖并提示冲突。
