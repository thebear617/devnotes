猪窝 v1.7.0 将原有美食记录升级为覆盖西安与南宁的双城市美食地图：地图、地点目录和详情弹窗统一围绕城市、区域、地点和坐标状态组织，形成一套可以持续补充的个人觅食记录系统。

## 双城市数据模型

- 新增 `city`、`region`、`tags`、`status`、`lng`、`lat`、`coordinateStatus` 与 `coordinateSource` 字段，保留旧有 `area` 字段用于校内 / 校外兼容。
- 美食地图支持西安与南宁切换；每个城市内部继续按区域、地点和搜索条件浏览，列表可以展示全部记录，地图只展示当前城市已确认坐标的地点。
- 将原始南宁美食清单中的 47 条记录导入内容集合，保留商圈、夜市、市场等原始上下文；缺少可靠门店信息的条目统一标记为待补坐标。

## 高德地图与交互

- 接入高德 JS API，加入城市中心点、坐标标记、地图与列表联动，以及点击地点查看菜品、地址、日期和评价的详情弹窗。
- 将高德默认大图钉替换为轻量自定义标记：默认隐藏地点名称，点击或聚焦后才显示当前店名，选中标记使用橙色高亮，减少多个地点同时显示文字造成的遮挡。
- 地图右上角新增「恢复默认视图」按钮。点击某家店放大后，可以一键回到当前城市的整体范围，重新适配全部已定位地点并清除选中状态。
- 地图页新增已定位 / 待补全图例、城市统计、地图使用提示和移动端适配。

## 坐标核查与维护

- 通过高德 POI 搜索核验并写入 22 个地点坐标，其中南宁 18 个、西安 4 个；其余 46 个地点保持待确认，不使用相似店铺或模糊区域猜测坐标。
- 新增美食地图数据契约与坐标核查清单，记录坐标来源、匹配地址、已确认地点和暂缓写入的原因。
- 增加 `.env.example`，明确高德 JS API Key 与安全配置的本地开发方式，并将真实环境变量排除在版本库之外。

构建生成 19 个页面通过，`git diff --check` 干净。
