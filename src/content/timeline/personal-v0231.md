熊窝 v0.23.1 聚焦生活仪表盘的天气信息与长期目标数据一致性：新增城市天气预报弹窗，并将追踪目标配置、浏览器本地数据和发布快照统一到同一套定义。

## 天气预报弹窗

- 西安、南宁和威海的天气卡片支持点击查看未来 5 天预报，展示天气类型、最高/最低温度、降雨概率和最大风速。
- 使用 Open-Meteo 预报接口，增加天气代码中文映射、移动端弹窗样式和 15 分钟的前端缓存；加载失败时显示明确提示。

## 追踪快照一致性

- 新增 `src/data/tracker-config.js`，集中维护「我要攒的钱」「别人还没还我的钱」「我要还别人的钱」等长期目标配置，当前储蓄目标为 13,028 元。
- 追踪看板会自动迁移旧的 localStorage 和发布快照，保留运行数据，同时用当前配置覆盖目标金额、名称和展示字段；正式站统一从 `/data/tracker-snapshot.json` 读取快照。
- 新增快照迁移脚本和校验脚本，避免旧目标金额或缺失字段继续进入正式数据。

## 发布校验

- Git push 前和 GitHub Pages 构建中都增加追踪快照校验，确保发布数据与源码配置一致。
