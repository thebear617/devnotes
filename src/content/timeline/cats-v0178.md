猫猫手册 v0.17.8 将小猫书从单纯的照片瀑布流推进为可筛选、可整理的素材空间。本版本同时补充了新的灵感视图和一批明信片素材，站点素材总数达到 373 张，其中 26 张被标记为明信片素材。

## 明信片素材体系

- 为每条本地素材记录补充 `isPostcard`、`author` 和 `photographedAt` 字段；普通素材默认不是明信片，明信片记录要求同时具备作者和拍摄日期。
- 在「猫猫素材」中新增「全部素材 / 明信片 / 普通素材」筛选，并支持通过 URL 直接进入明信片筛选视图。
- 明信片预览在图片上方显示「作者·拍摄日期」，大图预览和下载仍然使用原图。
- 新增一批义卖明信片素材，替换「大头·2026.06.19」的高清原图，并将合拍图按主要猫咪归档，避免素材重复展示和特殊字符路径失效。

## 素材浏览性能

- 瀑布流卡片统一加载 `thumb/` 缩略图，点击预览时再加载原图，下载入口继续保留原图。
- 为列表图片增加异步解码，降低大量高清素材同时参与下载、解码和布局时的浏览器压力。

## 猫猫灵感视图

- 新增「猫猫灵感」视图，用于保存明信片设计、猫猫图鉴和前端视觉参考。
- 开发环境提供灵感笔记的新增、编辑和删除入口，记录封面、来源链接、标题、标签和备注，并将本地图片资源一起纳入站点数据。

## 验证

- `npm run materials:validate`
- `SITE_BASE=/cat-knowledge/ npm run build`
- `node --check src/scripts/app/gallery.js`
- `git diff --check`
- 浏览器验证明信片筛选、缩略图请求和大图预览路径。
