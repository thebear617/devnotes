常识笔记 v1.3.0 完成了正式内容目录、frontmatter Schema 和本地 CMS 的一次整体收敛。

## 内容 Schema 统一

- 将七个领域的集合改为共享 Schema 工厂，领域只保留各自的分类配置和分类联动校验。
- `date` 与 `updated` 统一按日期字符串处理；`updated` 省略时回退到 `date`。
- 移除没有实际用途的 `topic`、`format` 和 `visible` 字段，简化 Markdown frontmatter 与 CMS 保存逻辑。
- 保留显式 `slug`，既有详情页地址不变。

## 内容目录迁移

- 50 个正式 Markdown 文件全部迁移为“领域 / 一级分类英文 / 二级分类英文 / 文件名”的双层目录结构。
- 最内层文件名统一使用对应二级分类的中文前缀，例如 `materials/quick-reference/速查对照：尺寸距离时长.md`。
- 对「省钱速查：省钱秘籍」和「人生阶段：人的一生」等前缀不一致的文章同步修正文件名与标题。

## 本地 CMS

- 文件与发布区域改为文件路径整行、日期并排、slug 独立一行的布局，路径提示随领域动态变化。
- 领域、分类和子分类下拉改用暖橙色自定义选择器，保留分类联动、选中状态和键盘关闭行为。
- 修复自定义下拉在表单 Flex 布局中按内容收缩的问题，恢复固定宽度。

## 验证

- 根路径和 `SITE_BASE=/lifenotes/` 构建均通过，共生成 59 个页面。
- 迁移后所有文章的 slug 和详情页 URL 保持不变。
